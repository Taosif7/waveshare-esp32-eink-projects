# External I2C OLED (SH1106 128×64)

A 4-pin module on the expansion-header I2C bus. Lab-checked on this board: the glass is 128×64 and the controller is an **SH1106**, even when the seller label says SSD1306.

| Item | Value |
|------|--------|
| Controller | SH1106 |
| Glass | 128 × 64 |
| I2C address | `0x3C`, also accept `0x3D` if that is what ACKs |
| Library | U8g2 `U8G2_SH1106_128X64_NONAME_F_HW_I2C` |
| Bus | Shared with TCA9554, ES8311, RTC, SHTC3, and the ADXL345 |
| Reference sketches | `oled-hello/`, `dino-oled/`, `odyssey-oled/`, `adxl-cube/`, `adxl-horizon/` |

## Wiring

| OLED pin | Header |
|----------|--------|
| VCC | **3V3** |
| GND | **GND** |
| SDA | **SDA** (GPIO18) |
| SCL | **SCL** (GPIO8) |

Do not power it from VSYS. That pin is about 5 V.

Constructor used by the sketches:

```cpp
U8G2_SH1106_128X64_NONAME_F_HW_I2C display(
    U8G2_R0, U8X8_PIN_NONE, /* clock */ 8, /* data */ 18);
```

`platformio.ini` in the OLED projects defines `OLED_SH1106`, which selects this constructor. `oled-hello` can be rebuilt as a 128×32 SSD1306 by commenting that flag and defining `OLED_128X32` instead. The module on this bench is the 128×64 SH1106.

Boot code probes `0x3C`, then `0x3D`, and prints an I2C scan until one answers.

## Why an SSD1306 driver looks broken

SH1106 RAM is 132 columns wide. The glass shows 128 of them, starting at column 2. An SSD1306 driver starts at column 0, so two unused columns sit on the right edge as a bright or dark line, and the picture is shifted. The SH1106 constructor sets that column offset. On this module the line went away and the picture moved two pixels once the driver matched the chip.

## Projects

| Project | What is on the glass |
|---------|----------------------|
| `oled-hello` | Animated HELLO WORLD |
| `odyssey-oled` | 121-frame loop, one frame every 67 ms (about 15 fps) |
| `dino-oled` | The Chrome runner, sprites scaled to 64 px tall. Same button as `dino-game` |
| `adxl-cube` | Wireframe cube tilted by the ADXL345. Bottom line is acceleration in g |
| `adxl-horizon` | Attitude indicator. Level pose is about halfway from flat toward upright |
